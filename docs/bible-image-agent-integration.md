# 圣经影像 AI · 经光知识源接入约定

> 独立私人应用消费经光现有知识源；不改动「经光」原有阅读、检索功能。

## 已有来源
- 圣经正文：`data/bible/`；关键词索引：`data/bible-search.json`。
- 圣经↔预言之灵关联：`data/bible-egw-relations.json` 和 `data/bible-egw-relations-extension.json`。
- 怀爱伦来源索引：`data/egw-index.json`。
- 官方中文书目：`data/egw-official-books.json`。

## 已有服务端 API
1. `GET /api/egw-search?q=<中文关键词>`：返回 `ok,q,count,results,official_url`。每条结果应提供原文地址 `url`，摘要 `snippet` 只能作为候选检索片段；接口依赖官方上游网页结构，有时可能失效。
2. `GET /api/egw-read?url=<encodeURIComponent(官方EGW网址)>`：返回 `ok,title,blocks,paragraphs,official_url,source_url`，错误场景需要停止引用；此接口只接受允许域名。
3. `GET /api/egw-read?url=<...>&toc=1`：章节目录；`meta=1`：章节元信息。

## 新的私人圣经影像 AI 调用流程
1. 用户上传图片或描述：模型识别候选事件和关键词（保留不确定性）。
2. 在圣经正文和经文索引中查到实际章节、经节。
3. 通过关系索引和 `/api/egw-search` 获取怀爱伦候选来源。
4. 仅当 `/api/egw-read` 返回可核对的来源、定位码和原文内容时，才能做直接引述；否则显示“尚未核实”。
5. 生成结构化画面事实清单：`明确经文`、`怀爱伦辅助记述`、`历史推测`、`用户确认的视觉偏好`。
6. 图像生成/局部修图；仅对可客观判断的结构执行视觉检查，未达到把握度不能声称“完全符合圣经”。
7. 定稿版本与源图片分开保存，用户显式确认后才能覆盖作品的定稿指针。

## 隔离与安全
- 私人影像 AI 建议使用**新的独立 GitHub 仓库与 Vercel 项目**，经光只提供知识源，不在经光项目内添加图片/视频模型密钥或生成任务。
- Vercel 服务端代理读取经光 API，浏览器不存放任何 AI API 密钥。
- 限制可调用的官方域名、响应大小、超时及调用频率；不开放任意 URL 代理。
- 不得未经授权批量镜像版权受限的中文怀爱伦著作全文；保留官方出处与来源标记。
- 搜索接口可能暂时返回空结果或 502，不要将失败当作“资料不存在”。
- 图像和视频 API 的收费不等于网页工具中的免费使用额度。

## 验收场景
母亲上传会幕图并说“按照出埃及记做正确”：
- 返回出埃及记 26–27 相关经文；
- 分清明确记载与视觉复原细节；
- 能识别入口五根柱子、外院规模与祭坛 5×5×3 肘；
- 如果源图仅一个局部错误，优先编辑，不擅自改颜色、角度与已认可的部分；
- 若原图主要结构错误，提出重做；
- 结果和原图同时保存，避免越修越错。
